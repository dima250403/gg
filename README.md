# Переписыватель текста

Полностью рабочее веб-приложение для переписывания текста с тремя режимами:

- **Аккуратный** — мягкая замена слов синонимами.
- **Деловой** — более формальная подача.
- **Креативный** — более свободная и вариативная формулировка.

## Запуск

Самый простой способ — через встроенный HTTP-сервер Python:

```bash
python3 -m http.server 4173
```

После этого откройте в браузере: `http://localhost:4173`.

## Как пользоваться

1. Вставьте исходный текст в левое поле.
2. Выберите режим и интенсивность.
3. Нажмите **«Переписать»**.
4. При необходимости используйте **«Скопировать результат»**.
